
# AI Student Assistant

Қазақ тіліндегі студенттерге арналған AI оқу көмекшісі. Жоба Streamlit + Python + Google Gemini API арқылы жасалған.

## Мүмкіндіктері
- AI Chat — студенттің сұрақтарына жауап береді.
- Study Helper — тақырыпты түсіндіреді, мәтінді қысқартады, флеш-карталар жасайды.
- AI Quiz — тақырып бойынша тест құрастырады, жауаптарды тексереді.
- Study Planner — оқу жоспарын жасайды.
- My Progress — тест ұпайлары мен белсенділікті көрсетеді.

## 1. Python орнату
Компьютерде Python 3.10 немесе одан жаңа нұсқа болғаны дұрыс.

## 2. Жобаны ашу
ZIP архивті шығарып, `AI_Student_Assistant` бумасын VS Code немесе PyCharm арқылы аш.

## 3. Виртуалды орта (ұсынылады)
Терминалда:

Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

## 4. Кітапханаларды орнату
```bash
pip install -r requirements.txt
```

## 5. Gemini API кілтін қосу (нақты AI жауаптары үшін)
1. Google AI Studio арқылы өзіңе API кілтін жаса.
2. `.streamlit` бумасының ішіндегі `secrets.toml.example` файлын көшіріп, атауын `secrets.toml` деп өзгерт.
3. Файл ішіне кілтіңді тырнақшаға алып жаз:

```toml
GEMINI_API_KEY = "ӨЗІҢНІҢ_API_КІЛТІҢ"
GEMINI_MODEL = "gemini-3.8-flash"
```

API кілтін ешкімге жіберме және GitHub сияқты ашық жерге жүктеме. `secrets.toml` жеке компьютеріңде ғана қалсын.

API кілтін қоспасаң да сайт демо режимінде ашылады: чат үлгі жауап береді, тест дайын сұрақтармен жұмыс істейді, оқу жоспары үлгі бойынша жасалады. Нақты генеративті AI мүмкіндіктері үшін API кілті керек.

## 6. Сайтты іске қосу
Жоба бумасының ішінде терминалға жаз:

```bash
streamlit run app.py
```

Браузерде Streamlit көрсеткен жергілікті адрес ашылады (әдетте `http://localhost:8501`).

## Жобаны көрсетуге арналған демонстрация
1. Басты беттен бес бөлімді көрсет.
2. AI Chat-қа: «Python тіліндегі циклді қарапайым тілмен түсіндір» деп жаз.
3. Study Helper бөлімінде «Жасанды интеллект» тақырыбын түсіндіртіп көр.
4. AI Quiz бөлімінде «Python циклдері» тақырыбына тест жаса.
5. Тестті орындап, нәтижесін көрсет.
6. Study Planner бөлімінде үш пән енгізіп, күндік жоспар құр.
7. My Progress бөлімінде ұпай мен белсенділік көрсеткіштерін көрсет.

## Қолданылған технологиялар

- Streamlit
- Google Gen AI Python SDK (`google-genai`)

## Ескерту
Бұл — оқу мақсатындағы демонстрациялық жоба. AI берген ақпаратты сенімді дереккөздермен тексеріп қолдан. Тест нәтижелері мен чат тарихы ағымдағы сессияда ғана сақталады.
